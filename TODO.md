- [ ] **Markdown deck rendered with the wrong theme.** `notes/12. Partial Differential Equations/12. Partial Differential Equations.marp` loses its two-column layout (`.two`) in imarp but not in `marp --watch` or Edge. Cause: the deck says `theme: chems`, but there's no `theme.css` beside it, so imarp silently renders with Marp's default theme (its HTML says `@theme default`). Marp CLI and VS Code get chems from `~/Library/marp/themes/chems.css` through `--theme-set` or settings, which the app can't see. Quick fix: put a copy of `chems.css` named `theme.css` beside the deck. Better: have imarp warn when the deck's `theme:` isn't found, and maybe let a deck's folder (or a parent folder) supply `<name>.css` themes like `--theme-set` does.
